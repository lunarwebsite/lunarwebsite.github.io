## 🚀 Deployment Guide
### **Deploy to GitHub Pages**

1.  **🍴 Fork the Repository**
    * Click the `Fork` button at the top right of this page to create your own copy of the respository.
    * *(If you name the respository "{your github username}.github.io", it gives you a better and shorter link.*

2.  **⚙️ Go to Settings**
    * In your new forked repository, go to the `Settings` tab.

3.  **🌍 Publish to Pages**
    * Go to the `Pages` section in the left sidebar.
    * Under `Build and deployment`, select the `main` branch as your source and click `Save`.
    * Your own copy of Lunar will be up and running in a few minutes at your URL
