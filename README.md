## 🚀 Deployment Guide

### **Deploy to GitHub Pages**

1.  **🍴 Fork the Repository**
    * Click the `Fork` button at the top right of this page to create your own copy of the repository.
    * *(If you name the repository "{your github username}.github.io", it gives you a better and shorter link.)*

2.  **⚙️ Go to Settings**
    * In your new forked repository, go to the `Settings` tab.

3.  **🌍 Publish to Pages**
    * Go to the `Pages` section in the left sidebar.
    * Under `Build and deployment`, select the `main` branch as your source and click `Save`.
    * Your own copy of Lunar will be up and running in a few minutes at your URL.

### **Deploy to Vercel**
[![Deploy with Vercel](https://binbashbanana.github.io/deploy-buttons/buttons/remade/vercel.svg)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Flunarwebsite%2Flunarwebsite.github.io)

### **Deploy to Netlify**
[![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start/deploy?repository=https://github.com/lunarwebsite/lunarwebsite.github.io)
